# Legacy Getting-Started Notes

This directory contains pre-monorepo Python-template artifacts. They are not
public documentation and must not be used for installation instructions.

The maintained TypeScript guidance is in the Sourcey pages
[`docs/introduction.md`](../introduction.md) and
[`docs/quickstart.md`](../quickstart.md). For contributor setup, use
[`docs/contributing.md`](../contributing.md).

If these legacy files are updated or removed, preserve only useful historical
context; do not reintroduce PyPI, `pip`, or Python-template instructions into
the public site.
